 TẦNG 3 — SYNC JOB (đọc staging → ghi entity đích, dùng chung mọi domain)
════════════════════════════════════════════════════════════════════════

IHrmSyncJob                                          HrmSyncResult
        ★ EntityType : string                                ★ TotalSource : int
        ★ SyncOrder : int = 0            [MỚI]                ★ Added : int
        ★ IsBlockingDependency : bool = false [MỚI]           ★ Updated : int
        ★ RunAsync(ct) : Task<HrmSyncResult>                  ★ Deactivated : int
                                                                ★ Unchanged : int
HrmSyncJob<TStaging,TEntity> : IHrmSyncJob                    ★ Superseded : int        [MỚI — cần thêm]
        ★ SyncOrder = 0 (virtual)                             ★ Errors : List<string>
        ★ IsBlockingDependency = false (virtual)               ★ Success : bool          [CẦN XÁC NHẬN field/logic]
        ★ RunAsync(ct):                                        ★ Summary : string
          1. pending = staging.Where(!IsProcessed).OrderBy(CreatedAt)
          2. group by EntityKey
          3. latest = mỗi nhóm lấy OrderByDescending(CreatedAt)
                       .ThenByDescending(Id).First()   [SỬA — thêm tiebreaker Id]
          4. superseded = phần còn lại mỗi nhóm → IsProcessed=true,
                          ErrorMessage="Superseded by newer change"
          5. LoadExistingEntitiesAsync(keys) → Dictionary<key,TEntity>
          6. foreach latest: switch(Action)
             - Delete → ApplyDelete(entity) nếu tồn tại
             - Insert/Update → entity null? MapToNewEntity : ApplyUpdate
             - try/catch riêng từng dòng → ghi staging.ErrorMessage, result.Errors
          7. AfterBatchAsync(batchContext, ct)  [virtual, no-op mặc định]
          8. SaveChangesAsync — BỌC try/catch [SỬA — nếu throw, cả batch
             rollback ngầm, phải reset result về trạng thái lỗi, KHÔNG để
             exception thoát ra ngoài RunAsync]
        ○ LoadExistingEntitiesAsync(keys,ct)      [abstract, hook]
        ○ MapToNewEntity(staging)                 [abstract, hook]
        ○ ApplyUpdate(entity,staging) : bool       [abstract, hook — true nếu có đổi]
        ○ ApplyDelete(entity) : bool                [abstract, hook — true nếu có đổi]
        ○ AfterBatchAsync(batchContext,ct)          [virtual, hook — ghi F03SyncReviewFlag]

Domain job cụ thể (ví dụ PositionHrmSyncJob):
        ★ EntityType => "Position"
        ★ IsBlockingDependency => true    [Department/Position — Employee phụ thuộc FK]
        - MapToNewEntity: set LastModifiedSource = SyncSourceTags.Hrm
        - ApplyUpdate: so field, nếu đổi → LastModifiedSource=Hrm;
                       TÁCH RIÊNG 2 case: đổi tên vs reactivate (SỬA — tránh
                       message sai ngữ nghĩa khi chỉ IsActive đổi)
        - ApplyDelete: IsActive=false, LastModifiedSource=Hrm, track deletedButReferenced
        - AfterBatchAsync: ghi F03SyncReviewFlag cho
          (a) ManualEditOverwrittenByHrm
          (b) ManualDeactivationOverwrittenByHrm  [MỚI — case Toggle bị ghi đè]
          (c) DeactivatedButStillReferenced

 CỜ ĐÁNH DẤU NGUỒN — chạy xuyên suốt mọi tầng, quyết định quyền ghi đè
════════════════════════════════════════════════════════════════════════

enum SyncSourceTags { Hrm, Manual }
        ★ THỨ TỰ KHAI BÁO — CẦN XÁC NHẬN GẤP: nếu Hrm = 0 (mặc định), bất kỳ
          entity nào bị tạo mà QUÊN set field này sẽ mặc định mang giá trị
          Hrm → bị DeleteAsync chặn xóa oan dù chưa từng đồng bộ.
          Khuyến nghị: Manual nên là giá trị mặc định an toàn hơn, hoặc
          đảm bảo MỌI nơi tạo entity (Mapper + base CreateAsync) đều set
          tường minh (đã áp dụng — nhưng vẫn nên xác nhận thứ tự enum).

Quy tắc bất biến cần giữ xuyên suốt:
  - Ghi bởi HrmSyncJob        → LastModifiedSource = Hrm
  - Ghi bởi Admin (Create/Update/Toggle qua Management Service) → Manual
  - DeleteAsync chỉ cho phép khi LastModifiedSource == Manual
  - HrmSyncJob.ApplyUpdate PHẢI so sánh wasManuallyEdited TRƯỚC khi ghi đè,
    và AfterBatchAsync PHẢI cảnh báo F03SyncReviewFlag nếu ghi đè giá trị
    Admin từng chỉnh tay
