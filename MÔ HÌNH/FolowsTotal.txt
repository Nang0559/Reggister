 APPROVAL WORKFLOW — 5 BƯỚC BẤT BIẾN (nguồn sự thật duy nhất)
─────────────────────────────────────────────────────────────────────────

BƯỚC 1 — PREVIEW (chưa có RequestId, dùng cho form tạo đơn)
  ApprovalRoleResolver.GetLeaveSteps()/GetOTSteps()
      → IEnumerable<(F03Approver Approver, bool Required)>
  ApprovalSubjectMapper.BuildStepDtos(resolvedSteps)   [Application — THUẦN DTO]
      → List<ApprovalStepSnapshotDto>
  IApprovalProvider<TSubject>.BuildHierarchyAsync(ctx,ct)
      → trả cho FE preview — CHƯA PERSIST

BƯỚC 2 — SUBMIT (RequestId đã có — gọi từ XxxOrchestrator.CreateAsync)
  IApprovalProvider<TSubject>.BuildSnapshotAsync(subject,ctx,ct)
      → ApprovalSnapshotDto(RequestId, ModuleName, CapturedAt, Steps)  ◄── record vị trí, đã xác nhận
  IApprovalEngine<TSubject>.InitializeStepsAsync(requestId,snapshotDto,ct)
      [Infrastructure]
      → ApprovalSnapshotEntityMapper.ToEntity(requestId, dto)  [Infrastructure — MỚI]
           RequestType = dto.ModuleName
           Steps: F03ApprovalStepSnapshot { Level, RoleName, ApproverCode,
                    ApproverName, ApproverEmail ◄── CỘT MỚI cần migration,
                    IsRequired }
      → PERSIST 1 LẦN DUY NHẤT — KHÔNG BAO GIỜ SỬA SAU
      → Engine.GetNextStepAsync → IApprovalNotificationService
        .NotifyNewRequestAsync   ── nối [D4]

BƯỚC 3 — APPROVE/REJECT (ghi History, KHÔNG đụng Snapshot)
  IApprovalEngine<TSubject>.ProcessDecisionAsync(action,ct)
      → Add F03ApprovalHistory { RequestId, RequestType, Level,
             StepId (= F03ApprovalStepSnapshot.Id, KHÔNG PHẢI Level),
             Decision, ApproverCode, ApproverName, Comment, ActionAt,
             IsOverriddenByAdmin, OverriddenByName, OverriddenAt }
      → APPEND-ONLY, NGUỒN SỰ THẬT DUY NHẤT "ai đã duyệt gì"
      → ApplyOverallStatusAsync (Provider ghi RequestStatus lên
        F03LeaveDay/F03OTRequest) → NotifyStepCompletedAsync  ── nối [D4]
      → TODO còn treo: rule chặn Admin override (ApproverRole check)

BƯỚC 4 — ĐỌC LẠI (tính lại mỗi lần, KHÔNG cache Calculated)
  ApprovalStepMapper.MapToCalculatedList(snapshot.Steps, histories)
      → List<ApprovalStepCalculatedDto>
  ApprovalStepMapper.ComputeOverallStatus(steps) → ApprovalStatus
  → dùng bởi: BaseRequestQueryService.LoadDetailsAsync,
              ApprovalListService<TDto>, IApprovalInboxService

BƯỚC 5 — REMINDER (state vận hành riêng)
  F03ApprovalReminderLog { RequestType, RequestId, Level, SentAt }  [MỚI —
      cần migration] → ghi bởi ApprovalEscalationService<TSubject>
      sau khi SendPendingRemindersAsync thành công, tránh nhắc trùng
      trong cùng ngày

 BẢNG QUY ƯỚC NAMESPACE — ÁP DỤNG CHO MỌI DOMAIN
═══════════════════════════════════════════════════════════════════════════

  Interface nghiệp vụ (IXxxService)         │ Application/Interfaces/{Domain}

  Response tổng hợp trả client              │ Contract/Responses
  Entity EF Core                            │ Core/Entities/{Domain}
  Implementation thật (EF/SQL/SignalR)      │ Infrastructure/Services/{Domain}
  Hub SignalR                               │ Infrastructure/Hubs
  Background Worker/Job                     │ Infrastructure/Jobs
  Controller                                │ API/Controllers
  Blazor Page/ClientService                 │ Shared/Pages | Shared/Services/{Domain}

  Project Reference (bắt buộc):
    Core        → (không gì)
